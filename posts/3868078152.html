取证

杂项取证，是计算机取证领域中的一种类型。它通常涉及多种不同的技术和方法，包括但不限于文件分析、隐写术、内存镜像分析、流量抓包分析等。


Volatility使用

Volatility是一款开源的基于Python开发的内存取证工具集，可以分析内存中的各种数据。它能够处理多种类型的内存文件，如.raw、.vmem、.img等，并提供丰富的命令用于分析这些文件。

Linux下载链接：Home of The Volatility Foundation | Volatility Memory Forensics - The Volatility Foundation - Promoting Accessible Memory Analysis Tools Within the Memory Forensics Community

Windows下载链接：Http://downloads.volatilityfoundation.org/releases/2.6/volatility_2.6_win64_standalone.zip

例如，使用imageinfo命令可以查看内存镜像的基本信息，使用pslist命令可以列出所有进程，而dumpfiles命令则可以导出内存中的文件

基本用法：

volatility.exe - f xxx.vmem --profile= [操作系统] 命令

AccessData FTK Imager使用

具体怎么构造镜像那些步骤，看大佬博客【电子取证篇】FTK Imager取证教程合集，看这一篇也够了 - ldsweely - 博客园 (cnblogs.com)，我这里只是简单说明如何使用E01这些文件

1、对于我们手上的镜像文件，

  • 我们可以点击Add Evidence Item添加本地镜像在软件内查看
  • 也可以点击Image Mounting将镜像挂载成本地的一个虚拟盘

2、如果点击的是Add Evidence Item，那么需要选择Image File，然后选择镜像的地址即可

3、点击Finish后会在软件内呈现这样的页面

4、如果需要挂载到本地，可以直接右击镜像，选择Image Mounting，当然，一开始选择Image Mounting接下来也是一样的步骤

5、点击Mount即可，来到本地，发现多了一个虚拟的磁盘F，接下来我们就可以在本地进行操作了

右击取证大师安装文件选择使用revo安装，安装结束后使用即可

task1

题目描述：请找出嫌疑人的操作系统主机名。

1、首先使用FTK Imager打开E01文件，把它挂到本地，方便我们查看

File -> Add Evidence Item -> image file -> 选择E01文件并按下Finish -> 右键E01文件 -> image Mounting -> Mount

2、要找到操作系统主机名，我们可以从注册表入手

这里利用注册表解析软件RegRipper4.0，将E01文件所在的盘里的System文件（盘符:root\windows\System32\config\SYSTEM）放到软件内，即可解析出一个txt文件，在里面可以看到主机名


task2

题目描述：请找出操作系统中安装的Android模拟器名称和安装日期。 格式：模拟器名时间 例子：雷电模拟器2022年06月23日

1、通过查看注册表内的信息，搜索player，发现是Nox（夜神）模拟器，时间也有，直接提交夜神模拟器2021年05月03日即可


task3

题目描述：请找出操作系统最后登录的用户

1、我们将\config文件夹下的sam文件解析成txt（还是使用注册表解析工具）

2、直接找到poiuy是最后登录的用户


task5

题目描述：请找出使用Bitlocker加密的虚拟磁盘文件。 格式：1.txt/2.txt

1、在虚拟磁盘上搜索.vhd(虚拟磁盘文件后缀，有时候是.vhdx)，发现用户poiuy下有两个磁盘

2、点进去发现确实是被加密了，那输入my.vhd/my1.vhd即可过关


task8

题目描述：请给出源磁盘的大小（字节）

这里直接查看虚拟磁盘，得知有32210153472字节，那么输入32210153472即可


task9

题目描述：请找出用户“poiuy”的SID

1、这里打开Sam.txt，查看类似SID格式的字符串，发现有一串后面的数字和poiuy一样都是1000，填入发现正确


task10

题目描述：请找出使用Bitlocker加密的虚拟磁盘文件恢复密钥文件名是什么。

1、刚刚我们找到了加密的磁盘，在同一个文件夹下有恢复密钥，经过测试，提交的文件名为666E6292-906B-4A9B-9167-4DB146123BAD.txt


Magnet AXIOM使用

链接：https://pan.baidu.com/s/1EAbBG15D6E5XyAbF3cDSfQ?pwd=2ldi

注意：安装完软件后先不要启动，把crack内的两个文件夹（AXIOM Process和AXIOM Examine）里的补丁分别复制替换掉原本安装路径上的文件，替换完即可使用软件

2、选择案件所在位置，点击“转至证据来源”

4、等待一段时间，Examine软件会自动打开，里面有分析后的信息，接下来就是取证环节了

task4

题目描述：请找出操作系统安装日期。 格式:2022-01-04 12:47:43

1、首先找到操作系统信息，但是这里的安装时间提交回显错误

2、看到时区这里，UTC和北京时间相差8个小时，那这里应该用所得的时间+8得到2021-05-03 18:44:28，提交发现成功

task11
