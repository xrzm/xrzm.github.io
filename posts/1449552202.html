XSS-labs靶场详解

发表于2024-07-22|更新于2024-07-24|web靶场

level1（直接输入payload）

payload：<script>(alert)(1)</script>


level2（闭合符号绕过）

输入<script>(alert)(1)</script>发现不行，查看源代码发现我们的payload被转义了，这里使用">对它进行闭合即可绕过。

payload："><script>(alert)(1)</script>


level3（onclick绕过htmlspecialchars）

1、输入payload后发现<>被转成html实体了，那这里就不能使用'>进行闭合了。

2、查看源码发现这道题使用htmlspecialchars函数把预定义的字符& " ' < >转换为HTML实体，防止浏览器将其作为HTML元素,

但是这个函数默认是只编码双引号的。

3、在输入payload后点击输入框即可过关

payload:'onclick='alert(1)（第一个单引号和value闭合，后面的单引号联合将alert包裹起来）


level4（onclick绕过）

输入payload后查看源代码发现<和>被过滤掉了，但是这里和第三关差不多，使用双引号闭合配合onclick即可

payload："onclick="alert(1)


level5（js绕过）

1、输入payload查看源代码发现payload前面的<script>被修改成了<scr_ipt>，说明<script>被过滤了，尝试onclick发现on也被过滤了。

2、把javascript: 后面的代码当JavaScript来执行从而实现绕过。

输入payload后点击click就能进入level6了。

payload："><a href="javascript:alert(1)">click</a>


level6（大小写绕过）

经过尝试，发现script、on、src、href都被过滤了，找payload时发现可能是大小写绕过，在输入payload后点击click即可下一关。

payload："><a Href="javascript:alert(1)">click</a>


level7（双写绕过）

输入<script、on、src、href、data，发现都被过滤了，大小写也过滤了，这里使用双写绕过即可过关

payload："><scscriptript>alert(1)</sscriptcript>


level8（html编码绕过）

1、输入">'><script、on、src、href、data进行尝试，发现除了单引号，其他都被过滤了，那么这里应该要使用编码绕过了

2、同时留意到经过处理后的字符串是在a href标签内的，那么我们可以将javascript:alert(1)进行html编码，输入后再点击“友情链接”即可

payload：&#106;&#97;&#118;&#97;&#115;&#99;&#114;&#105;&#112;&#116;&#58;&#97;&#108;&#101;&#114;&#116;&#40;&#49;&#41;


level9（判断是否需要http://）

1、输入" sRc DaTa OnFocus <sCriPt> <a hReF=javascript:alert()> &#106;来查看过滤了什么，发现回显链接不合法

2、查看源码发现这里如果没有http://那么会回显链接不合法。

3、那我们在上一题的后面添加上http://，并使用注释符将它注释起来防止执行不了弹窗。

payload：&#106;&#97;&#118;&#97;&#115;&#99;&#114;&#105;&#112;&#116;&#58;&#97;&#108;&#101;&#114;&#116;&#40;&#49;&#41;/* http:// */


level10（hiden修改）

1、输入" sRc DaTa OnFocus <sCriPt> <a hReF=javascript:alert()> &#106;检测发现数据被隐藏了

2、查看源码，发现这里是get传参t_sort，并过滤掉了<>号，不能闭合插入标签，但是我们还能用onfocus事件，因为这里输入框被隐藏了，需要添加type="text"，构造payload

3、直接get传参payload后点击输入框即可

payload：?t_sort=" onfocus=javascript:alert() type="text


level11（referer头注入）

1、查看源码发现这道题也是隐藏了value值，但是有一个特殊的点，这题多了一个参数t_ref，并且它的参数是前一个页面的地址，那么我们可以猜测这个参数就是referer头

2、使用burpsuite进行抓包，添加Referer头，内容为" onfocus=javascript:alert() type="text

3、放包后点击输入框即可下一关

payload：Referer: " onfocus=javascript:alert() type="text


level12（User-Agent头注入）

1、查看源代码发现新的参数是UA头，那这一题的思路和上一题的差不多

2、抓包后重放再点击输入框即可

payload：" onfocus=javascript:alert() type="text


level13（cookie头注入）

这一题跟上面两题都差不多，只不过要在cookie处进行注入，在Cookie： user=后面填入payload即可

payload：" onfocus=javascript:alert() type="text


level14（没完成）

这道题就给了一个网站，但是这个网站无法访问，下一题。


level15（ng-include）

1、查看源代码发现ng-include，搜索得知ng-include指令用于包含外部的 HTML 文件。

ng-include属性的值如果是一个表达式，返回一个文件名，如果包涵的内容是地址，需要加引号。

默认情况下，包含的文件需要包含在同一个域名下。

2、我们输入" ' sRc DaTa OnFocus <sCriPt> <a hReF=javascript:alert()> &#106;检测这道题过滤了什么，发现只过滤了双引号和<>，那可以用单引号来包裹一个地址。

3、我们输入?src='/level1.php'得知是可以包含level1.php

4、我们可以包涵第一关并让第一关弹窗（注意，这里不能包涵那些直接弹窗的东西如<script>，但是可以包涵那些标签的东西比如<a>、<input>、<img>、<p>标签等等，这些标签是能需要我们手动点击弹窗的）我们手动点击Click即可

payload：?src='level1.php?name=<a href=javascript:alert(1)>Click</a>'


level16（回车绕过空格）

1、输入" ' sRc DaTa OnFocus <sCriPt> <a hReF=javascript:alert()> &#106;检测这道题过滤了什么，得知这里过滤了srcipt和空格

2、尝试用/来替代空格也不行，这里可以用回车来代替绕过，回车的url编码是%0a

payload：<img%0asrc%0aonerror=alert(1)>


level17（embed标签，拼接绕过）

1、查看源代码发现，这道题引用了swf文件（FLASH插件的文件）并且有embed标签（<embed> 标签定义了一个容器，用来嵌入外部应用或者互动程序（插件））

2、这里我去后端改了一下代码，将后端第十七关的代码（level17.php）指向的swf文件改为index.png（效果是一样的）

<embed>标签可以用onclick或onmouseover绕过。因为这两个变量是互相拼接起来的，所以在输入arg02时在b之后加一个空格，当浏览器解析到b的时候就停止判断，然后将onclick或onmouseover看作另外一个属性。

输入payload后点击图片即可

payload：?arg02= onclick=alert()


level18（拼接绕过）

这里首先和第十七题一样，先更改swf文件成index.png，输入payload即可

payload：?arg02= onclick=alert()


level19、20（反编译）

这里涉及到了flash的反编译，放弃了。
