SQL数据库类型判断

常见的数据库：Oracle、MySQL、SQL Server、Access、Postgresql，mongodb等

前端与数据库类型

asp：SQL Server，Access
.net：SQL Server
php：MySQL，PostgreSQL
java：Oracle，MySQL

根据数据库特有函数来判断

len和length

len()：SQL Server 、MySQL以及db2返回长度的函数。
length()：Oracle和INFORMIX返回长度的函数。

version和@@version

SQL Server：select@@version –
Oracle :select banner from v$version
MySQL：select @@version，version() –
PostgreSQL: select version() –

substring和substr

MySQL两个函数都可以使用
Oracle只可调用substr
SQL Server只可调用substring

根据特殊符号进行判断

/*是MySQL数据库的注释符
--是Oracle和SQL Server支持的注释符
;是子句查询标识符，Oracle不支持多行查询，若返回错误，则说明可能是Oracle数据库
#是MySQL中的注释符，返回错误则说明可能不是MySQL，另外也支持-- 和/**/

数据库特有表

数据库 表名
MySQL information_schema.tables
Access msysobjects
SQL Server sysobjects
Oracle all_tables
PostgreSQL pg_catalog.pg_tables
SQLite sqlite_master

Oracle数据库渗透思路

  1. 对数据库端口进行扫描
  2. 对数据库版本相关信息进行收集
  3. 获取数据库SID安全的值
  4. 数据库提权

Oracle提权方法

  1. SET_OUTPUT_TO_JAVA：利用DBMS_JAVA.SET_OUTPUT_TO_JAVA()函数的特性提升权限
  2. GET_DOMAIN_INDEX_TABLES：利用PL/SQL Injection提升权限
  3. LT.FINDDDRICSET：利用SYS.LT.FINDRICSET函数的注入漏洞提升权限
  4. SDO_DROP_USER_BEFORE：触发器漏洞（触发器是独立存储的对象，由事件触发运行）
