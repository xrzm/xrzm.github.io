MySQL版本区别

  • MySQL < 5.0：没有information_schema，多用户单操作。
  • MySQL > 5.0：多用户多操作。

MySQL注入点

  • 写一句话条件：root绝对路径、load_file、union查询、web目录写权限、into outfile

Access数据库处理

MySQL 5.7特性

  1. 随机root密码
  2. test数据库
  3. 默认SSL
  4. 密码过期策略
  5. 用户锁
  6. 全面支持JSON
  7. 支持两类生成列（generated column）
  8. 引入系统库（sys schema）

MySQL渗透思路

  1. 端口、版本信息收集
  2. 数据库管理信息收集
  3. 暴力破解
  4. 查看是否有源代码或文件包泄露漏洞
  5. 使用phpMyAdmin账号获取webshell，或利用CMS漏洞获取webshell

Oracle数据库渗透思路

  1. 对数据库端口进行扫描
  2. 对数据库版本相关信息进行收集
  3. 获取数据库SID安全的值
  4. 数据库提权

Oracle提权方法

  1. SET_OUTPUT_TO_JAVA：利用DBMS_JAVA.SET_OUTPUT_TO_JAVA()函数的特性提升权限
  2. GET_DOMAIN_INDEX_TABLES：利用PL/SQL Injection提升权限
  3. LT.FINDDDRICSET：利用SYS.LT.FINDRICSET函数的注入漏洞提升权限
  4. SDO_DROP_USER_BEFORE：触发器漏洞（触发器是独立存储的对象，由事件触发运行）
